by the owner on 2026-08-26. Card groups colours by where they're meant to be used
(Facade / Trims / Roofs). No hex values are given on the card itself — only the
colour name and Berger's own product code — and the card explicitly warns shades
shown are indicative only, so don't invent/guess hex values from the photo; refer
to the physical Berger ColorBank fandeck before tinting or displaying "true" swatches.
